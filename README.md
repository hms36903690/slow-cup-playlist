# Slow Cup Jazz

카페 재즈 유튜브 플레이리스트 채널 운영 앱입니다. 설치 없이 브라우저에서 바로 열립니다.

- `index.html`: Slow Cup Jazz 앱. 이 파일 하나로 모든 기능을 씁니다.
- `playlist.html`: 예전 플레이리스트 앱 주소. 지금은 `index.html`로 바로 넘어갑니다.

## 여는 방법

- `index.html`을 더블클릭하면 브라우저에서 바로 열립니다.
- 이렇게 연 경우 보관함·일정·성과 기록은 **그 브라우저에만** 저장됩니다. 보관함의 "백업 복사"로 데이터를 따로 보관하세요.
- AI 가사 쓰기와 AI 주제 추천 버튼은 claude.ai 아티팩트로 열었을 때만 나타납니다.
- 썸네일 "PNG로 저장"이 안 되는 환경에서는 아래 큰 이미지를 오른쪽 클릭(PC)하거나 길게 눌러(휴대폰) 저장하세요.

## 앱 다운로드 · 설치

### 휴대폰·PC에 앱으로 설치하기 (추천)

GitHub Pages가 켜져 있으면 아래 주소에서 앱처럼 설치할 수 있습니다. 설치하면 아이콘이 생기고, 인터넷이 없어도 열립니다.

**https://hms36903690.github.io/slow-cup-playlist/**

- **안드로이드 (Chrome)**: 주소를 열고 오른쪽 위 **앱 설치** 버튼을 누릅니다. 버튼이 없으면 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**.
- **아이폰 (Safari)**: 주소를 열고 아래쪽 **공유 버튼** → **홈 화면에 추가**.
- **PC (Chrome·Edge)**: 주소를 열고 오른쪽 위 **앱 설치** 버튼, 또는 주소창 오른쪽의 설치 아이콘을 누릅니다.

### 파일로 내려받기 (ZIP)

**https://github.com/hms36903690/slow-cup-playlist/archive/refs/heads/main.zip**

압축을 풀고 `index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 이렇게 연 경우에는 앱 설치와 오프라인 기능이 작동하지 않습니다.

### 저장 관련 안내

- 설치한 앱이든 파일이든, 보관함·일정·성과 기록은 **그 기기에만** 저장됩니다. 휴대폰과 PC에 따로 저장돼요.
- 기기를 바꾸거나 브라우저 데이터를 지우기 전에 보관함의 **백업 복사**로 내용을 보관하세요.
- AI 가사 쓰기, AI 주제 추천, 썸네일 바로 저장은 claude.ai 링크로 열었을 때만 나타납니다.

## 기능

| 탭 | 하는 일 |
|---|---|
| 만들기 | Suno용 Style·Exclude·Lyrics 프롬프트와 곡 제목 생성, 플레이리스트 만들기(여러 곡 한번에, 기본 13곡·최대 40곡) |
| 업로드 | 썸네일 시안(날씨별 창가 배경, 배치 3가지, 내 이미지, PNG 저장), 제목 후보·설명란·타임스탬프·해시태그 (보관함의 영상용 곡, 없으면 방금 만든 플레이리스트 기준) |
| 보관함 | 곡별 진행 상태와 "유료 플랜에서 생성" 여부 기록 |
| 일정·기록 | 30일 업로드 일정(화·목·토), 영상 성과 기록 |


## 영상 자동 제작 도구 (`tools/`)

### `tools/playlist_maker.py`: 음원 합치기·타임스탬프·영상 만들기

고른 곡들을 명령어 한 번으로 한 편의 영상으로 만듭니다.

1. 폴더 안의 음악 파일을 **파일 이름 순서대로** 이어 붙입니다 (곡 사이 3초 크로스페이드).
2. 처음 페이드인, 마지막 페이드아웃을 넣습니다.
3. 유튜브 기준 음량(-14 LUFS)으로 맞춥니다.
4. 설명란에 붙일 **실제 곡 길이 기준 타임스탬프**를 만듭니다.
5. 배경 이미지(앱에서 만든 썸네일 등)와 합쳐 1080p mp4 영상을 만듭니다.

필요한 것: Python 3, [ffmpeg](https://ffmpeg.org/download.html) (둘 다 무료)

```bash
python playlist_maker.py 음악폴더 --image 배경.png --out 비오는날카페재즈
```

- 파일 이름 앞에 번호를 붙이면 그 순서대로 이어집니다. 예: `01_Rain Letter.mp3`, `02_Window Seat.mp3`
- 번호와 `_`는 타임스탬프 제목에서 자동으로 빠집니다.
- 결과: `비오는날카페재즈.mp4`, `비오는날카페재즈_mix.m4a`, `비오는날카페재즈_timestamps.txt`

### `tools/window-seat-studio.html`: 예전 기획 도구

다른 대화에서 "Window Seat Café" 채널 이름으로 만들었던 기획 도구입니다. 영상 기획, 타임스탬프 계산, 업로드 일정, 성과 기록, 키워드 노트가 들어 있습니다. 대부분 Slow Cup Jazz 앱과 겹치며, 참고용으로 보관합니다.
